# v1.0.8 功能更新摘要

本文记录 `v1.0.7` 到 `v1.0.8` 合并到 `main` 时带入的主要能力、修复和重构，便于发布说明、回归测试和后续维护对照。

## 新增能力

- **AI 翻译与对话工具**：新增 AI 翻译工具和 AI 聊天页面，支持流式响应、历史记录持久化、AI 配置管理与简单 Markdown 渲染。
- **Telegram 签到工具**：集成 TDLib，新增 Telegram 签到页与聊天窗，支持消息文本选择、通过本地代理收发。
- **浏览器历史管理**：新增独立历史浏览页，支持查看、搜索和清理浏览历史，滚动时自动收起搜索框。
- **桌面模式与视口控制**：浏览器支持桌面/移动视口切换，桌面模式通过重建 WebView 立即生效，窄屏设备提供分页操作面板。
- **Web 调试控制台**：新增页面内 Web 调试控制台，配合多项浏览器性能修复。
- **视频缓存与测速控制**：原生视频播放增加媒体缓存与速度测试控制；时间覆盖层支持显示毫秒。
- **下载管理增强**：下载记录与文件分离，支持独立删除下载文件或仅清除记录。
- **更多工具面板优化**：浏览器“更多”面板重新梳理，操作项更紧凑清晰。

## 可靠性与兼容性修复

- **SOCKS5 / 代理**：CONNECT 回复与载荷原子分离发送、Hysteria2 IPv6 目标格式化、Telegram 下行流保留与首包延迟、Hysteria2 下 Telegram 稳定性提升。
- **弹窗与外部链接**：规范化前捕获原始弹窗 URL、保留编码后的外部应用 URL、弹窗对话框保持解码一致，修复跨应用跳转丢失参数问题。
- **浏览器**：强制刷新卡死页面、桌面模式 WebView 重建、视口模式即时应用、收藏搜索对齐、本地标签保留。
- **运行日志**：提升运行日志覆盖面、会话间重置运行日志，便于问题定位。
- **生命周期**：Telegram 与悬浮层（overlay）生命周期收敛，多 ABI 构建与文件管理器布局加固。

## 代码重构

- **WebView 拆分**：导航控制器、事件控制器、脚本服务、状态读取器、诊断与弹窗 URL 解析器等从 `browser_page` 抽离，单文件复杂度显著下降。
- **Android 通道独立化**：悬浮视频、媒体扫描、代理核心、时间覆盖、翻译覆盖等拆为独立 `ChannelHandler` + `Service`。
- **设置与表单**：代理节点控制器、代理表单变更器、设置表单控制器独立，代理设置页逻辑清晰化。
- **远程控制平台接入**：平台相关访问集中到 `RemoteControlPlatformGateway`，远控服务与页面辅助层进一步收敛。
- **视觉简化**：应用整体视觉设计与服务边界整理，界面更轻量一致。

## 性能优化

- AI 聊天流式渲染与历史队列效率优化，长对话滚动与渲染更顺滑。

- 扩展 UI 设计规范与项目引导文档（`docs/ui-design.md` / `ui-design.en.md` 及开发、架构文档）。

- 沿用 `scripts/build_multi_abi.sh` 多 ABI 发布构建：生成 `app-arm64-v8a-release.apk` 与 `app-armeabi-v7a-release.apk`。

## 建议回归重点

1. **AI 工具**：翻译、AI 聊天流式输出、历史记录保存与加载、AI 设置项。
2. **Telegram**：签到流程、聊天消息文本选择、经本地代理收发、Hysteria2 链路下的稳定性。
3. **浏览器**：历史浏览页搜索/清理、桌面/移动模式切换、Web 调试控制台、弹窗与外部链接跳转、强制刷新。
4. **视频**：媒体缓存与测速、毫秒级时间覆盖、解析器 endpoint 全量兼容。
5. **代理**：SOCKS5 大流量转发、IPv6 目标、诊断日志开关。
6. **下载**：记录与文件分离删除、下载页播放。
