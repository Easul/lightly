# Lightly 界面设计规范

[English](ui-design.en.md)

## 设计目标

Lightly 的界面服务于浏览器、网络连接、本地服务和远程控制等高密度功能。设计重点是：

- 信息清晰，避免为了装饰增加层级
- 组件紧凑，但保留足够的点击区域与上下留白
- 全局使用统一主题色，不为每个功能创建一套独立配色
- 危险操作可识别，但不使用刺眼的大面积红色
- 标准弹窗、底部菜单和设置列表保持一致的视觉语言

## 设计源文件

- 全局主题与颜色：`lib/theme/app_theme.dart`
- 通用设置行：`lib/widgets/shared/setting_tile.dart`
- 设置分组容器：`lib/browser/widgets/settings/settings_section_widgets.dart`
- 浏览器“更多”宫格：`lib/browser/widgets/browser_more_actions_sheet.dart`
- 长按操作列表：`lib/browser/widgets/browser_long_press_actions_sheet.dart`
- 自定义断开提示：`lib/pages/remote_control_disconnect_dialog.dart`

新页面优先复用这些组件和 `Theme.of(context).colorScheme`，不要在页面内重复定义接近但不一致的颜色、圆角和阴影。

## 颜色体系

当前浅色主题的核心令牌：

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| 主题色 | `#6D9F5B` | 激活状态、主按钮、重点图标 |
| 浅主题容器 | `#E4EFE0` | 选中背景、轻量强调 |
| 页面背景 | `#F3F5F2` | Scaffold 与分组间隔 |
| 内容背景 | `#FFFFFF` | 卡片、底部弹窗、对话框 |
| 主文字 | `#3F4742` | 标题与主要信息，避免纯黑 |
| 次文字 | `#7B837E` | 描述、默认菜单图标与辅助信息 |
| 分隔线 | `#E8ECE7` | 轻量边界，不使用重描边 |
| 危险色 | `#B66C6C` | 删除、退出、断开、错误 |
| 危险容器 | `#F7ECEC` | 危险提示背景 |

规则：

- 普通功能不要使用红色、橙色或纯黑强调。
- 激活状态优先使用主题绿，不额外发明“功能专属色”。
- 错误提示使用 `colorScheme.error` / `errorContainer`，不要直接使用 `Colors.red`。
- 视频画面、远程屏幕、播放器控制层等沉浸场景可以保留黑色背景。

## 尺寸与圆角

- 页面左右边距通常使用 `12` 或 `16`。
- 内容卡片圆角使用 `18`。
- 输入框和主要按钮圆角使用 `14`。
- 标准对话框圆角使用 `22`，底部弹窗顶部圆角使用 `24`。
- 主要按钮默认高度为 `48`，避免使用过高的胶囊按钮。
- 设置列表单行最小高度由全局 `ListTileTheme` 控制，不在业务页面随意增大。
- 阴影只用于需要与背景分离的浮层，普通卡片默认无阴影或极轻阴影。

## 弹窗分类

### 短操作：宫格弹窗

适用于“更多”这类文字短、数量有限、图标可快速识别的操作集合。

- 宽度不小于 `380` 时使用 5 列，否则使用 4 列。
- 图标大小保持在 `23` 左右，文字约 `11.5`。
- 默认图标和文字使用次文字色；激活项使用主题色；危险项使用低饱和危险色。
- 每个项目保留足够上下留白，不使用图标背景圆块和额外箭头。
- 操作触发前先关闭弹窗，避免后续导航与 BottomSheet 动画竞争。

参考实现：`BrowserMoreActionsSheet`。

### 长操作：文字列表弹窗

适用于包含较长文字、URL 预览或需要逐行阅读的菜单。

- 使用纵向 `ListTile`，标题左对齐。
- 默认不放置大号 leading 图标；需要表达可进入下一层时使用轻量右箭头。
- 分组通过留白或浅色块区分，不连续堆叠厚重分割线。
- URL、说明等辅助信息使用次文字色，并限制最大行数。

参考实现：收藏菜单、页面长按菜单、计算器复制菜单。

### 确认与输入弹窗

- 优先使用全局 `AlertDialog` 主题。
- 标题简短，正文说明结果和风险，按钮不超过三个。
- 普通取消操作使用文本按钮，主要操作使用主题色按钮。
- 删除、退出、断开等危险操作使用危险色，但避免整块高饱和红色背景。
- 输入较多或内容会被键盘遮挡时使用 `isScrollControlled` 的底部弹窗。

## 列表与设置页

- 设置首页按功能域分成不同白色块，目前分为浏览设置、网络与本地服务、远程控制等区域。
- 每个分组内部使用简洁设置行：标题、单行说明和右箭头。
- 不为每一行再创建独立描边卡片，也不使用大号彩色图标容器。
- 详细设置页可使用 `SettingsCard` 组合输入框、开关和状态信息。
- 同一分组中的行使用轻量分隔线；不同分组之间使用页面背景形成 `12` 左右的间隔。

## 状态与危险操作

- 正常、已启用、已连接：主题绿。
- 未启用、次要、不可用：次文字灰或 outline 色。
- 错误、停止、删除、退出：低饱和危险色。
- 不要仅依赖颜色传达状态，同时保留文字、图标或禁用状态。
- 远程控制、代理和 EasyTier 的错误内容可能较长，提示区域应允许换行。

## 性能边界

- 不要为了动画或颜色变化在 WebView 高频回调中触发父页面 `setState()`。
- BottomSheet 内部列表保持稳定尺寸，避免在动画过程中使用不必要的 `shrinkWrap`。
- 不在浏览器、视频和远程画面热路径增加阴影动画、模糊或高频渐变计算。
- 主题调整不应改变 WebView keepAlive、代理连接、远控 socket 或服务生命周期。

## 新界面检查清单

- [ ] 颜色来自 `AppTheme` / `ColorScheme`，没有新增相近的硬编码主题色。
- [ ] 标题、正文和辅助文字层级清楚，没有大面积纯黑文字。
- [ ] 操作数量少时使用紧凑布局，文字较长时使用纵向列表。
- [ ] 设置项按功能分组，不连续堆叠独立大卡片。
- [ ] 危险色只用于真正危险的操作。
- [ ] 小屏幕、键盘弹出和系统字体放大时不会溢出。
- [ ] WebView、代理、视频、远控等性能敏感逻辑没有因 UI 调整而改变。

## 验证建议

```bash
flutter analyze
flutter test
```

涉及浏览器弹窗或设置页时，至少手动检查：

1. 360dp 左右窄屏与较宽设备上的“更多”宫格列数和文字截断。
2. 长按链接、收藏菜单、清理数据和输入类弹窗。
3. 设置首页分组、详细设置页和开关禁用状态。
4. 视频、远程屏幕和键盘场景仍保持必要的可读性与沉浸效果。
