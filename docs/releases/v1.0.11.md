# Lightly v1.0.11

本次发布在 `v1.0.10` 基础上新增本地/在线音乐播放器，并集中修复 YouTube 长视频解析、
浮动视频播放手势与时长显示问题。

## 下载

| 文件 | 架构 | 适用设备 |
|---|---|---|
| `app-arm64-v8a-release.apk` | ARM64 / 64 位 | 大多数现代 Android 设备 |
| `app-armeabi-v7a-release.apk` | ARMv7 / 32 位 | 旧设备或 32 位系统 |

请同时下载 `SHA256SUMS` 校验 APK。最低系统版本为 Android 7.0。

## 主要更新

### 音乐播放器

- 新增音乐播放器，支持手动配置音乐 API 地址，并明确提示鉴权失败。
- 在线音乐支持搜索、浏览、分组播放模式和通知栏播放入口。
- 支持下载到本地音乐库：文件名规范为“歌手-标题”，保留封面、歌词和元数据。
- 已下载音乐在刷新、合并同标题曲目或切换 remote-id 副本时不会丢失元数据。
- 支持自然排序、批量删除、恢复播放提示和本地/在线统一播放队列。

### YouTube 解析修复

- 长视频（1 小时以上）解析不再只拿到约半小时内容：捕获到的分段媒体请求会按完整时长
  归一化后再交给播放器。
- 已解析过的 watch 页面会复用缓存的页面结果，减少重复加载导致的超时。
- Google 验证页（Sorry 拦截）只在 watch 导航阶段判定，嵌入的验证资源不再误伤正常解析。
- 页面内导航期间保持解析轮询，避免 20 秒预算被一次导航白白耗尽。
- 解析诊断日志有界且不输出 Cookie 或完整签名 URL。

### 浮动视频播放器

- 视频时长超过 1 小时时正确显示小时位。
- 左侧双击快退 5 秒，右侧双击快进 5 秒。
- 横向拖动可预览目标时间点，松手后才跳转，避免拖过头或拖不够。
- 长按画面 3 倍速播放，松开恢复原速。
- 小窗模式只保留关闭按钮，不再挤压进度条和控制按钮；双击小窗恢复完整控制界面。

## 升级提示

- YouTube 原生解析需要先在 Lightly 浏览器内登录 YouTube。
- 本版本需要新的 `yt-resolver` AAR；Release 构建通过
  `YOUTUBE_RESOLVER_AAR_URL` / `YOUTUBE_RESOLVER_AAR_SHA256` Actions 变量固定来源。
- 音乐 API 需要在音乐播放器设置中手动配置；鉴权失败会明确提示。

完整技术说明见 [v1.0.11 完整更新说明](../release-summary-v1.0.11.md)。
