# Lightly v1.0.10

本次发布汇总 `v1.0.8` 之后的功能、稳定性、架构和交付流程调整。`v1.0.9` 是这一批工作的
中间发布点；当前 `v1.0.10` 同时更新了 YouTube resolver。

## 下载

| 文件 | 架构 | 适用设备 |
|---|---|---|
| `app-arm64-v8a-release.apk` | ARM64 / 64 位 | 大多数现代 Android 设备 |
| `app-armeabi-v7a-release.apk` | ARMv7 / 32 位 | 旧设备或 32 位系统 |

请同时下载 `SHA256SUMS` 校验 APK。最低系统版本为 Android 7.0。

## 主要更新

### 原生能力按需安装

- Telegram TDLib、WebRTC 语音和 EasyTier JNI/FFI 已拆为同签名纯 Android companion。
- 宿主 APK 不再重复携带这些功能的 Flutter/Dart runtime；每个插件按 ABI 单独交付。
- Lightly 内置插件 URL、大小、SHA-256、包名和 API 要求，并在安装与绑定前校验同签名。
- 插件下载支持 Lightly 代理、GitHub 直连，以及连接失败/空闲超时/持续低速后的镜像回退。

### YouTube 播放

- 集成私有 Android YouTube resolver，通过登录态短生命周期 MWEB 捕获最终 itag 18 MP4 请求。
- YouTube 页面先正常打开，只有点击页内播放按钮才解析；解析前会暂停当前网页媒体。
- 标题和必要请求头可进入浮动播放器与下载器，但 Cookie 和完整媒体地址不会写入日志。
- 固定新版 resolver AAR 及其 SHA-256：改进播放器就绪检测、移动视口、渲染进程异常处理、轮询
  预算和 CDN 重定向稳定性。

### 下载与站点数据

- 下载保留目标站点 Cookie、User-Agent 和脱敏 Referer，并对跨 origin 重定向移除敏感 headers。
- 支持瞬态错误自动重试、Range 断点续传、ETag/Last-Modified 校验和失败记录重新下载。
- 改进 `Content-Disposition` / `filename*`、query、最终 URL 和 MIME 文件名解析。
- 普通失败保留部分文件；下载记录与文件可以分别删除。
- 当前站点清理覆盖 Cookie、WebStorage、IndexedDB、Cache API 和 Service Worker，不清除其他站点
  或全局 WebView 缓存。

### 兼容性与性能

- 修复代理绕过 host 边界，避免 `googlevideo.com` 错误命中 `google.com` 后直连并返回 403。
- 浏览器弹层期间合并非关键页面刷新，保持 WebView keepAlive，降低掉帧、白屏和旧标签残影。
- 降低远控视频统计分配、Telegram 普通 update 日志解析和 EasyTier 重复 JNI 轮询。
- WebRTC companion 补齐 Android/MIUI 麦克风前台启动、网络权限、有线/USB/蓝牙耳机动态路由。
- Telegram companion 修复 SOCKS5 应用时机、代理运行时刷新、TDLib 单 receive 线程和 MIUI
  `dataSync` 前台生命周期。

### 架构与发布

- 完成 `lib/app/` composition root、运行时协调器、typed platform gateway 和主要 feature 目录迁移。
- Browser、Proxy、EasyTier、Remote Control 和 Floating Video 的生命周期资源保持单一 owner。
- 发布流程固定并校验私有 YouTube AAR；companion 未变化时复用已发布 manifest，变化时使用同一
  keystore 重建六个 APK 并与最终 Lightly 验签。
- 修复 detached tag 构建、CI Gradle 安装和不同 `apksigner` 输出格式兼容性。

## 升级提示

- 从旧的宿主内 TDLib 首次迁移到 Telegram companion 需要重新登录一次；之后同签名升级保留会话。
- Telegram、WebRTC 或 EasyTier 首次使用时可能提示安装 companion。
- YouTube 原生解析需要先在 Lightly 浏览器内登录 YouTube。
- 远控仍会按需请求录屏、无障碍、麦克风/Nearby devices 或 VPN 权限。

完整技术说明见 [v1.0.10 完整更新说明](../release-summary-v1.0.10.md)。

---

This release consolidates all feature, stability, architecture, and delivery work after `v1.0.8`.
Highlights include pure-Android optional companions for Telegram/WebRTC/EasyTier, authenticated and
resumable downloads, native YouTube MWEB resolution, proxy host-boundary correctness, lower browser
and remote-control hot-path overhead, explicit runtime ownership, and a pinned/verifiable release
supply chain. See the [English release summary](../release-summary-v1.0.10.en.md) for full details.
