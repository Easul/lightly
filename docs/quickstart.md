# Lightly 快速入门

[English](quickstart.en.md)

## 安装

1. 前往 [Releases](https://github.com/Easul/lightly/releases) 下载最新 APK
2. 根据设备架构选择：
   - `app-arm64-v8a-release.apk`：64 位设备
   - `app-armeabi-v7a-release.apk`：32 位设备
3. 在 Android 上完成安装并授予必要权限

## 首次使用

首次启动后，你可以按下面顺序快速体验：

1. **浏览器**：直接访问网页，验证基础浏览能力
2. **代理**：前往 **设置 → 代理**，填入 VLESS 链接
3. **远程控制**：前往 **设置 → 远程控制** 启动服务，在同一局域网浏览器访问对应地址
4. **P2P VPN**：前往 **设置 → P2P VPN** 配置 EasyTier 网络
5. **文件 / 剪贴板服务**：按需在设置中启用本地 HTTP 服务、文件简易管理和剪贴板同步

## 什么时候用 Lightly

| 场景 | 使用方式 |
|------|----------|
| **手机之间互控** | 用手机浏览器打开另一台手机的远程控制地址，实时查看屏幕并操作 |
| **跨网络远程控制** | 配置 EasyTier 后，优先使用 EasyTier 虚拟 IP 建立远控与 WebRTC 语音链路 |
| **局域网剪贴板同步** | 设备 A 复制 → 设备 B 粘贴，无需第三方云服务 |
| **访问代理站点** | 配置 VLESS 节点，通过 WebView 访问需要代理的网页 |
| **设备间文件传输** | 启用 HTTP 文件服务，浏览器直接上传/下载 |
| **网页编辑手机文件** | 启用 **设置 → 文件简易管理**，用网页浏览文件树、编辑文本、删除文件并收藏路径 |
| **后台视频播放** | 浏览器检测到视频后，点击悬浮播放，切换应用到后台继续听 |

## 核心能力

### 浏览器
- 多标签页管理
- 地址栏建议
- 视频检测与悬浮播放
- 下载管理

### 代理
- 支持 VLESS over WebSocket / TLS
- 支持 HTTP / SOCKS5 本地混合代理

### 远程控制
- 屏幕捕获，部分机型会自动降级到兼容的编码尺寸以避免黑屏
- 触摸注入
- WebRTC 双向语音与剪贴板同步

**控制界面操作：**
- 鼠标左键/单指点击 = 手机触摸点击
- 鼠标拖拽/单指滑动 = 滑动手机屏幕
- 双指缩放 = 手机屏幕缩放
- 手机视频/音频会同步到浏览器播放

### 本地服务
- HTTP 文件服务器（默认 3001）
- 文件简易管理（默认目录 `/storage/emulated/0`，默认端口 12580）
- 剪贴板 HTTP 服务（默认 12345）

**文件简易管理操作：**
- 在设置页启动服务后，手机本机可访问 `http://127.0.0.1:12580`
- 同一局域网电脑可访问设置页展示的手机 IP 地址
- 支持常见文本文件（Markdown、TXT、HTML、LOG、TOML、YAML 等）编辑保存
- 删除文件前会弹出确认框，收藏路径在网页左侧下方独立滚动显示

## 常见问题

### 代理无法连接
- 检查 VLESS 链接格式
- 检查节点的 host、path、sni 是否正确
- 确认远端服务可访问

### 远程控制打不开
- 确认手机和控制端在同一局域网
- 确认远程控制服务已启用
- 检查端口是否被占用

### 远程画面黑屏或语音中断
- 先确认网络稳定；EasyTier 网络波动会触发自动重连，但弱网下仍可能短暂黑屏或静音
- 红米等机型如果不支持全分辨率 AVC 编码，应用会自动尝试较低分辨率捕获
- 控制端说话、被控端听不到时，可重新开关语音按钮触发音频路由刷新；新版本也会自动检测 receiver 端远端音频停滞并恢复

### 视频播放异常
- 先尝试清理站点数据或缓存
- 确认当前站点允许应用内播放
